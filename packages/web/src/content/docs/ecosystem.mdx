A collection of community projects built on Noxijent.

:::note
Want to add your Noxijent related project to this list? Submit a PR.
:::

You can also check out [awesome-noxijent](https://github.com/awesome-noxijent/awesome-noxijent) and [noxijent.cafe](https://noxijent.cafe), a community that aggregates the ecosystem and community.
