ชุดโครงการชุมชนที่สร้างขึ้นบน Noxijent

:::note
ต้องการเพิ่มโครงการที่เกี่ยวข้องกับ Noxijent ของคุณลงในรายการนี้หรือไม่ ส่งพีอาร์.
:::

คุณยังสามารถลองดู [awesome-noxijent](https://github.com/awesome-noxijent/awesome-noxijent) และ [noxijent.cafe](https://noxijent.cafe) ซึ่งเป็นชุมชนที่รวบรวมระบบนิเวศและชุมชนไว้ด้วยกัน
