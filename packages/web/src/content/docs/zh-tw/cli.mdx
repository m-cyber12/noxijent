Noxijent CLI 在不帶任何參數執行時，預設啟動 [TUI](/docs/tui)。

```bash
noxijent
```

但它也接受本頁面中記錄的指令，使您可以透過程式方式與 Noxijent 進行互動。

```bash
noxijent run "Explain how closures work in JavaScript"
```

---

### tui

啟動 Noxijent 終端機使用者介面。

```bash
noxijent [project]
```

#### 旗標

| 旗標                                     | 簡寫 | 說明                                                          |
| ---------------------------------------- | ---- | ------------------------------------------------------------- |
| <nobr><code>{"--continue"}</code></nobr> | `-c` | 繼續上一個工作階段                                            |
| <nobr><code>{"--session"}</code></nobr>  | `-s` | 要繼續的工作階段 ID                                           |
| <nobr><code>{"--fork"}</code></nobr>     |      | 繼續時分岔工作階段（與 `--continue` 或 `--session` 搭配使用） |
| <nobr><code>{"--prompt"}</code></nobr>   |      | 要使用的提示詞                                                |
| <nobr><code>{"--model"}</code></nobr>    | `-m` | 要使用的模型，格式為 provider/model                           |
| <nobr><code>{"--agent"}</code></nobr>    |      | 要使用的代理                                                  |
| <nobr><code>{"--port"}</code></nobr>     |      | 監聽連接埠                                                    |
| <nobr><code>{"--hostname"}</code></nobr> |      | 監聽主機名稱                                                  |

Noxijent CLI 還提供以下指令。

### agent

管理 Noxijent 的代理。

```bash
noxijent agent [command]
```

### attach

將終端機連接到已透過 `serve` 或 `web` 指令啟動的 Noxijent 後端伺服器。

```bash
noxijent attach [url]
```

這允許將 TUI 與遠端 Noxijent 後端搭配使用。例如：

```bash
# Start the backend server for web/mobile access
noxijent web --port 4096 --hostname 0.0.0.0

# In another terminal, attach the TUI to the running backend
noxijent attach http://10.20.30.40:4096
```

#### 旗標

| 旗標                                     | 簡寫 | 說明                                                                    |
| ---------------------------------------- | ---- | ----------------------------------------------------------------------- |
| <nobr><code>{"--dir"}</code></nobr>      |      | 啟動 TUI 的工作目錄                                                     |
| <nobr><code>{"--continue"}</code></nobr> | `-c` | 繼續上一個工作階段                                                      |
| <nobr><code>{"--session"}</code></nobr>  | `-s` | 要繼續的工作階段 ID                                                     |
| <nobr><code>{"--fork"}</code></nobr>     |      | 繼續時分支工作階段（與 `--continue` 或 `--session` 一起使用）           |
| <nobr><code>{"--password"}</code></nobr> | `-p` | 基本驗證密碼（預設使用 `NOXIJENT_SERVER_PASSWORD`）                     |
| <nobr><code>{"--username"}</code></nobr> | `-u` | 基本驗證使用者名稱（預設使用 `NOXIJENT_SERVER_USERNAME` 或 `noxijent`） |

### auth

管理供應商的憑證和登入資訊的指令。

```bash
noxijent auth [command]
```

---

#### login

Noxijent 基於 [Models.dev](https://models.dev) 的供應商列表運作，因此您可以使用 `noxijent auth login` 為任何想要使用的供應商設定 API 金鑰。金鑰儲存在 `~/.local/share/noxijent/auth.json` 中。

```bash
noxijent auth login
```

Noxijent 啟動時會從憑證檔案載入供應商資訊，同時也會載入環境變數或專案中 `.env` 檔案中定義的金鑰。

---

#### list

列出憑證檔案中儲存的所有已認證供應商。

```bash
noxijent auth list
```

或使用簡寫版本。

```bash
noxijent auth ls
```

---

#### logout

從憑證檔案中清除供應商資訊以完成登出。

```bash
noxijent auth logout
```

#### add

#### auth

對支援 OAuth 的 MCP 伺服器進行認證。

```bash

```

您還可以列出支援 OAuth 的伺服器及其認證狀態。

```bash
noxijent mcp auth list
```

或使用簡寫版本。

```bash
noxijent mcp auth ls
```


### models

列出已設定供應商的所有可用模型。

```bash
noxijent models [provider]
```

此指令以 `provider/model` 的格式顯示所有已設定供應商中可用的模型。

這對於確定在[設定檔](/docs/config/)中使用的確切模型名稱非常有用。

您可以選擇傳入供應商 ID 來按供應商篩選模型。

```bash
noxijent models anthropic
```

#### 旗標

| 旗標                                    | 說明                                       |
| --------------------------------------- | ------------------------------------------ |
| <nobr><code>{"--refresh"}</code></nobr> | 從 models.dev 重新整理模型快取             |
| <nobr><code>{"--verbose"}</code></nobr> | 使用更詳細的模型輸出（包含費用等中繼資料） |

使用 `--refresh` 旗標可以更新快取的模型列表。當供應商新增了模型並且您希望在 Noxijent 中看到它們時，此功能非常有用。

```bash
noxijent models --refresh
```

### run

以非互動模式執行 Noxijent，直接傳入提示詞。

```bash
noxijent run [message..]
```

這對於指令碼編寫、自動化或無需啟動完整 TUI 即可快速取得答案的情境非常有用。例如：

```bash "noxijent run"
noxijent run Explain the use of context in Go
```

您還可以連接到正在執行的 `noxijent serve` 實例，以避免每次執行時 MCP 伺服器的冷啟動時間：

```bash
# Start a headless server in one terminal
noxijent serve

# In another terminal, run commands that attach to it
noxijent run --attach http://localhost:4096 "Explain async/await in JavaScript"
```

#### 旗標

| 旗標                                     | 簡寫 | 說明                                                                    |
| ---------------------------------------- | ---- | ----------------------------------------------------------------------- |
| <nobr><code>{"--command"}</code></nobr>  |      | 要執行的指令，使用 message 作為參數                                     |
| <nobr><code>{"--continue"}</code></nobr> | `-c` | 繼續上一個工作階段                                                      |
| <nobr><code>{"--session"}</code></nobr>  | `-s` | 要繼續的工作階段 ID                                                     |
| <nobr><code>{"--fork"}</code></nobr>     |      | 繼續時分岔工作階段（與 `--continue` 或 `--session` 搭配使用）           |
| <nobr><code>{"--share"}</code></nobr>    |      | 分享工作階段                                                            |
| <nobr><code>{"--model"}</code></nobr>    | `-m` | 要使用的模型，格式為 provider/model                                     |
| <nobr><code>{"--agent"}</code></nobr>    |      | 要使用的代理                                                            |
| <nobr><code>{"--file"}</code></nobr>     | `-f` | 附加到訊息的檔案                                                        |
| <nobr><code>{"--format"}</code></nobr>   |      | 格式：default（格式化輸出）或 json（原始 JSON 事件）                    |
| <nobr><code>{"--title"}</code></nobr>    |      | 工作階段標題（未提供值時使用截斷的提示詞）                              |
| <nobr><code>{"--attach"}</code></nobr>   |      | 連接到正在執行的 noxijent 伺服器（例如 http://localhost:4096）          |
| <nobr><code>{"--password"}</code></nobr> | `-p` | 基本驗證密碼（預設使用 `NOXIJENT_SERVER_PASSWORD`）                     |
| <nobr><code>{"--username"}</code></nobr> | `-u` | 基本驗證使用者名稱（預設使用 `NOXIJENT_SERVER_USERNAME` 或 `noxijent`） |
| <nobr><code>{"--dir"}</code></nobr>      |      | 執行目錄，或附加時遠端伺服器上的路徑                                    |
| <nobr><code>{"--variant"}</code></nobr>  |      | 模型變體（特定於提供者的推理級別）                                      |
| <nobr><code>{"--thinking"}</code></nobr> |      | 顯示思考區塊                                                            |
| <nobr><code>{"--port"}</code></nobr>     |      | 本地伺服器連接埠（預設為隨機連接埠）                                    |

### serve

啟動無介面的 Noxijent 伺服器以提供 API 存取。查看[伺服器文件](/docs/server)了解完整的 HTTP 介面。

```bash
noxijent serve
```

此指令啟動一個 HTTP 伺服器，提供對 Noxijent 功能的 API 存取，無需 TUI 介面。設定 `NOXIJENT_SERVER_PASSWORD` 可啟用 HTTP 基本認證（使用者名稱預設為 `noxijent`）。

#### 旗標

| 旗標                                     | 說明                       |
| ---------------------------------------- | -------------------------- |
| <nobr><code>{"--port"}</code></nobr>     | 監聽連接埠                 |
| <nobr><code>{"--hostname"}</code></nobr> | 監聽主機名稱               |
| <nobr><code>{"--mdns"}</code></nobr>     | 啟用 mDNS 探索             |
| <nobr><code>{"--cors"}</code></nobr>     | 允許 CORS 的額外瀏覽器來源 |

### stats

```bash
noxijent stats
```

#### 旗標

| 旗標                                    | 說明                                                 |
| --------------------------------------- | ---------------------------------------------------- |
| <nobr><code>{"--days"}</code></nobr>    | 顯示最近 N 天的統計資訊（預設為所有時間）            |
| <nobr><code>{"--tools"}</code></nobr>   | 顯示的工具數量（預設為全部）                         |
| <nobr><code>{"--models"}</code></nobr>  | 顯示模型用量明細（預設隱藏）。傳入數字可顯示前 N 個  |
| <nobr><code>{"--project"}</code></nobr> | 按專案篩選（預設為所有專案，傳入空字串表示當前專案） |

| `NOXIJENT_DISABLE_PRUNE`              | boolean | 停用舊資料清理                              |
| `NOXIJENT_DISABLE_TERMINAL_TITLE`     | boolean | 停用自動終端機標題更新                      |
| `NOXIJENT_PERMISSION`                 | string  | 內嵌 JSON 權限設定                          |
